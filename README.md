## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Any Challenge Locally
```bash
npm run dev:01   # Hotel Booking Confirmation
npm run dev:02   # Crowdfunding Product Page
npm run dev:03   # Intro Section with Dropdown Navigation
npm run dev:04   # Weather App
npm run dev:05   # Notifications Page
npm run dev:06   # Tip Calculator App
npm run dev:07   # Fylo Landing Page
npm run dev:08   # E-commerce Product Page
npm run dev:09   # Contact Form Solution
npm run dev:10   # Four Card Feature Section
npm run dev:11   # Social Proof Section
npm run dev:12   # Mortgage Repayment Calculator
npm run dev:13   # Base Apparel Coming Soon
npm run dev:14   # Product List with Cart
npm run dev:15   # FAQ Accordion
npm run dev:16   # Device Shop Checkout
npm run dev:17   # Ping Coming Soon Page
npm run dev:18   # Intro Component with Signup Form
npm run dev:19   # Newsletter Sign-up Form
npm run dev:20   # Profile Card Component
npm run dev:21   # Huddle Single Section Landing Page
```

### 3. Build All Projects
```bash
npm run build
```
